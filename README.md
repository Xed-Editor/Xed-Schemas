## Xed-Editor Schemas

This repository acts as a registry for validation schemas.
It includes the following JSON schemas:

- https://raw.githubusercontent.com/Xed-Editor/Xed-Schemas/main/extension.json
  > Validation for extension `manifest.json` files
- https://raw.githubusercontent.com/Xed-Editor/Xed-Schemas/main/theme-manifest.json
  > Validation for theme `manifest.json` files
- https://raw.githubusercontent.com/Xed-Editor/Xed-Schemas/main/theme.json
  > Validation for theme `theme.json` files
- https://raw.githubusercontent.com/Xed-Editor/Xed-Schemas/main/icon.json
  > Validation for icon pack `manifest.json` files
- https://raw.githubusercontent.com/Xed-Editor/Xed-Schemas/main/manifest.json
  > **New**: Validation for `manifest.json` files, new `.xed` package format
